### Systems architect & forward-deployed technical operator

I build production systems at the intersection of automation, data, AI, integrations, infrastructure, and real-world operations.

These repositories are a curated, sanitized sample of systems I've built and operated over the past six months. Several originated in private production infrastructure, n8n workflows, or live organizational systems; their GitHub commit dates reflect when I packaged them for public review, not when the underlying work was done.

I use AI coding tools heavily as implementation leverage. I own the requirements, architecture, system boundaries, validation, security decisions, debugging, deployment, and production outcomes.
